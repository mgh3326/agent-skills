# installer 배포 체크리스트 (1회 배포당 1부)

사이트 특정값(호스트·경로·명령 문자열·창 시간 숫자)은 이 파일에 적지 않는다 — 사이트
정본(비공개)을 참조한다. 각 항목은 증거 1줄을 남긴 뒤에만 체크한다.

## 입력 확인 (R2)

- [ ] 0a. head SHA 확보 — 증거: `<SHA>` → <있음|없음>
- [ ] 0b. 머지된 PR 목록 확보 — 증거: `<PR 목록 또는 출처>` → <있음|없음>
- [ ] 0c. 배포창 판정 근거 확보 — 증거: `<승인 문구 또는 창 시간 판정>` → <있음|없음>
- [ ] 0d. 배포 기록 키 확보(R12, 스폰 입력) — 증거: `<deploy/<service>/YYYYMMDDTHHMMSSZ>` → <있음|없음>
- [ ] 0e. 0a~0d 중 하나라도 없음 → **ESC, 시작하지 않음**(증거: 위 항목 참조) — 기록 키가 있으면 단계 9 실행(`failed_step`=`0`)

## 고정 절차 9단계 (R3)

- [ ] 1. 대상 확정 — 증거: `<확정된 SHA/PR 목록>` `<현재 배포본 실측값 또는 "실측 실패">` → <진행|ESC>
- [ ] 2. 이미지/아티팩트 존재 확인 — 증거: `<확인 명령/결과, 대기 경과 시간>` → <진행|대기|ESC>
- [ ] 3. DB 마이그레이션 판정 — 증거: `<파일:리비전>` `<판정 additive|non-additive>` → <진행|ESC>
- [ ] 4. additive 일 때만 선적용 — 증거: `<적용 결과 또는 "해당 없음(non-additive/마이그레이션 없음)">` → <진행|ESC>
- [ ] 5. 배포 명령 실행 — 증거: `<exit code>` → <진행(exit=0)|ESC(exit≠0, 재시도 없음)>
- [ ] 6a. 서빙 digest 일치 — 증거: `<관측값>` → <PASS|FAIL>
- [ ] 6b. 컨테이너 healthy — 증거: `<관측값>` → <PASS|FAIL>
- [ ] 6c. 헬스 엔드포인트 200 — 증거: `<관측값>` → <PASS|FAIL>
- [ ] 6d. 실시간 피드 재접속 증거 — 증거: `<관측값>` → <PASS|FAIL>
- [ ] 6e. 오류 로그 0 — 증거: `<관측값>` → <PASS|FAIL>
- [ ] 6f. 부하 정상 — 증거: `<관측값>` → <PASS|FAIL>
- [ ] 6g. 6a~6f 중 1건이라도 FAIL → **ESC**(증거: 실패 항목 인용)
- [ ] 7. 체크포인트 기록 — 증거: `<체크포인트 경로/시각>` → <완료>
- [ ] 8. JOIN 보고 — 증거: `<director로 전달한 경로/시각, 8줄 증거 포함 여부>` → <완료>

## 단계 9 — 배포 기록 (R12, 성공·실패·ESC 모두 — ESC로 멈췄어도 ESC 보고 뒤 반드시 실행)

- [ ] 9a. 본문 필드 13개 전부(모르는 값 `null`, 추측 0) · result 규칙 적용 — 증거: `<result>` `<failed_step>` → <진행>
- [ ] 9b. 부재 확인 — 증거: `<읽기 명령 출력이 "없음">` → <진행|ESC(트리거 8)>
- [ ] 9c. 쓰기 — 증거: `<exit code>` → <진행(exit=0)|ESC(트리거 8, 재시도 없음)>
- [ ] 9d. 새로 생성 확인 — 증거: `<생성 시각 = 갱신 시각>` → <완료|ESC(트리거 8, 덮어쓰기 관측)>
- [ ] 9e. 9b~9d 중 ESC → 트리거 8 ESC 보고서에 기록 본문 원문 첨부 — 증거: `<ESC 경로/시각>`

## 범위 밖 자가 점검 (R8, 위반 시 즉시 중단)

- [ ] 머지·push 없음 — 증거: <점검 방법>
- [ ] 브랜치 보호 변경 없음 — 증거: <점검 방법>

- [ ] 롤백 결정 없음(자동 롤백 결과는 보고만) — 증거: <점검 방법>

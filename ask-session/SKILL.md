# ask-session — 세션 질의·답변 회수 왕복

**원칙: 침묵은 답변이 아니다.** 답변 파일이 기한 내 없으면 "무응답"이 결과다 — 추측으로
채우거나, 이전 대화 내용을 답변인 양 인용하거나, 무한 재질의하지 않는다.

## 1. 질의 구성 — 답변 계약을 질문에 포함

- **답변 파일 경로를 질문자가 지정**: `~/work/herdr-inbox/answer-<질문자>-<주제>-<HHMM>.md`
  (유일 이름, 질의 전 `ls`로 부재 확인). 화면 답변은 유실되니 **파일 작성이 계약**이다.
- 질문에 반드시 포함: ①누가 왜 묻는지(출처) ②답변 형식(요약/표/판정 등) ③기한
  ("<N>분 내") ④"모르면 '모름'과 그 근거를 적어라 — 추측 금지" ⑤답변 파일 경로.
- 머리에: `(같은 질문이 두 번 보이면 재답변 금지)`.

## 2. 주입 — relay-handoff 절차 재사용

- **relay-handoff 스킬의 §2(대상 검증)·§3(주입+제출 검증)을 그대로 따른다.**
- 대상이 `herdr agent list`에 없으면(세션 사망·재시작) **실패로 보고하고 운영자
  에스컬레이션** — 질문자가 임의로 대상 세션을 재스폰하지 않는다(orch/캡틴 재생성은
  운영자 결정).

## 3. 답변 대기·회수

```bash
# 파일 출현 폴링 (기본 타임아웃 10분 — 무거운 질의는 질문에 명시한 기한 + 여유)
end=$((SECONDS+600))
until [ -f "$ANSWER_FILE" ] || [ $SECONDS -gt $end ]; do sleep 10; done
```

- `herdr agent wait --status idle`은 **보조 신호일 뿐** — kiro/agy는 작업 중에도 idle/done
  오표시(status 플랩), claude는 다른 작업으로 working일 수 있다. 완료 판정은 파일로만.
- **타임아웃 시 폴백 순서**: ①`herdr agent read <target> --lines 40`으로 답변이 화면에만
  있는지 확인 — 있으면 인용하되 "파일 미작성, 화면 전사본" 명시 ②없으면 "무응답
  (기한 N분 경과)"으로 보고하고 운영자에게 표면화. 재질의는 1회까지, 헤더에
  `[재질의 — 이전 질의 무응답]` 명시.

## 4. 보고 형식

- 질문 요지 1줄 / 답변 파일 경로 + 핵심 답변 / 왕복 소요 시간
- 무응답·화면전사·재질의였다면 그 사실을 그대로 (정상 왕복인 척 금지)

## 설계 배경

- 답변 채널이 파일인 이유: 세션 pane에 send로 회신하면 사용자 타이핑과 충돌(실사고),
  화면 출력은 스크롤/compact로 유실된다. 인박스 파일은 durable하고 어느 에이전트든 읽는다.
- 이 스킬은 relay-handoff(단방향 전달)의 왕복 확장이다 — 질의도 결국 "답변 계약이 붙은
  릴레이"다.
